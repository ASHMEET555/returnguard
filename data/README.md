# Data Directory

The `raw/` and `processed/` directories are gitignored to avoid committing large datasets and artifacts.

- `raw/`: Raw generated transaction, order, customer, and dispute records.
- `processed/`: Featurized and split datasets (`train.parquet`, `val.parquet`, `test.parquet`).

All data in these folders is regenerated by running the synthetic generator in `data/generator/`.
